# MCP Config Manager — Releases

This repository contains **compiled installers only**. Source code is not published here.

## Download

Get the latest release for your platform from the [Releases page](https://github.com/awfmilton/mcp-manager-releases/releases).

| Platform | File |
|---|---|
| Windows 10/11 | .exe installer |
| macOS | .dmg |
| Linux | .AppImage or .deb |

### macOS note (beta)

Right-click the .dmg and choose **Open**, then click **Open** again in the dialog. This is only needed until the app is signed with an Apple Developer certificate.
